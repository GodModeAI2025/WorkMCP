MCP-Server · Open Source · lokal betrieben

Der Job-Graph für Deutschland, als Kontext für jedes Agent-Harness.

WorkMCP verbindet Stellenanzeigen, Berufe, Aufgaben, Skills, Gehälter und Automatisierungssignale aus öffentlichen Quellen zu einem Graphen. Jeder Abruf wird gemerkt, neue und geänderte Daten werden versioniert ergänzt.

Schnellstart Code auf GitHub Faktencheck

Vom Beruf zur Automatisierung

Rolle→ KldB · ISCO · ESCO · O*NET→ Aufgaben→ Skills→ Automatisierung

Ein Aufruf von get_role_context('Buchhalter') liefert Zuordnung, Aufgaben, Skills, Medianentgelt und Marktsignal.

Erneuter Abruf, Delta im Gedächtnis

neu: 3 geändert: 1 (Version 2) nicht mehr enthalten: 2 unverändert: 19

Alte Versionen bleiben erhalten. Nichts wird stillschweigend überschrieben oder gelöscht.

Was WorkMCP kann

24 Tools und ein Analyse-Prompt für Claude Code, OpenCode und andere MCP-fähige Harnesses, per stdio lokal oder per Streamable HTTP zentral.

Stellen aus drei Quellen

BA-Jobsuche als Deutschland-Kern, Arbeitnow mit Remote- und Visa-Filter, ATS-Karriereseiten direkt (Greenhouse, Lever, Ashby, Personio, Workday u. a.) mit Abteilung und Seniority.

Berufe und Aufgaben

BERUFENET-Tätigkeiten mit KldB-Code, ESCO-Skills (essential/optional), O*NET Task Statements (Core/Supplemental), KldB-Hierarchie als Jobfamilien.

Crosswalks

KldB ↔ ISCO-08 ↔ ESCO ↔ O*NET ↔ BERUFENET, auch über mehrere Stufen. Grundlage sind importierte amtliche Tabellen.

Gehaltsbänder

Amtliche Medianentgelte mit Quartilen aus dem Entgeltatlas der BA, nach Region, Niveau, Branche. Optional Gehalts-Histogramme aus Adzuna.

Automatisierungssignale

Hacker-News-Berichte zu automatisierten Tätigkeiten, verknüpfbar mit Aufgaben. Bewertungen mit Arbeitszeitanteil speichert das Modell per record_extraction.

Graph und Export

Knoten und Kanten mit Herkunft, Export als JSON, Neo4j-Cypher, GraphML oder als verlinkte Archivy-Wissensdatenbank.

Das Gedächtnis: merken und ergänzen

Alles liegt lokal in einer SQLite-Datenbank: Datensätze, Versionen, ein Änderungsprotokoll, Abruf-Läufe, ein Volltextindex und der Graph.

Anfrage

Innerhalb der Gültigkeitsdauer kommt die Antwort sofort aus dem Speicher.

Abruf

Ein Inhalts-Hash je Datensatz entscheidet: neu, geändert oder unverändert.

Ergänzen

Geänderte Daten bekommen eine neue Version mit feldgenauem Diff, verschwundene einen Status.

Ausfallsicher

Ist eine Quelle nicht erreichbar, kommt der letzte Stand mit Warnung. Ein Offline-Modus ist eingebaut.

"gedaechtnis": {
  "aus_speicher": false, "stand": "2026-10-29T09:12:04+00:00",
  "delta": { "neu": ["10002-1000000001-S"],
             "geaendert": [{"schluessel": "10000-1184867112-S", "version": 2,
                            "aenderungen": [{"feld": "stellenangebotsTitel", "alt": "Buchhalter (m/w/d)", "neu": "… – Teilzeit"}]}],
             "nicht_mehr_enthalten": ["10001-1002716922-S"], "unveraendert": 19 } }

Schnellstart

Voraussetzungen: Python ≥ 3.10 und uv.

Claude Code (lokal, stdio)

claude mcp add workmcp -- uvx --from git+https://github.com/GodModeAI2025/WorkMCP workmcp

Docker: WorkMCP + Archivy

cp .env.example .env
docker compose up -d --build

Archivy unter localhost:5000 mit vorinstallierter Doku, WorkMCP unter localhost:8000/mcp. export_knowledge('archivy') schreibt direkt nach Archivy.

Zentral (Streamable HTTP)

workmcp --transport streamable-http --host 0.0.0.0 --port 8000
claude mcp add --transport http workmcp http://<server>:8000/mcp

Der HTTP-Modus hat keine eigene Authentifizierung. Nur intern oder hinter einem geschützten Reverse Proxy betreiben.

Erste Schritte im Harness

check_sources()
import_reference_data('onet')
get_role_context('Buchhalter', ort='Berlin')
